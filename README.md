# CareLoop

A menstrual migraine self-care companion prototype with deterministic recorded-pattern analysis and an optional Tencent Cloud ADP explanation.

## Run locally

1. Install Node.js LTS (v20+), then run `npm install`.
2. Copy `.env.example` to `.env` and set `ADP_APP_KEY` to the AppKey for the published CareLoop Insights agent. Keep this file local; `.env` files are Git-ignored.
3. In one terminal, run `npm run server`.
4. In a second terminal, run `npm run dev` and open the local URL printed by Vite.

Vite proxies `/api` requests to the local server at `127.0.0.1:8787`. To verify the connection, open **AI Insights**, click **Generate AI Explanation**, and confirm that the result is labelled as generated by Tencent Cloud ADP. The browser sends aggregate synthetic counts only; the AppKey is added by the server and is never returned to the browser.

In development, the backend logs safe connection diagnostics: local route, credential presence as a boolean, upstream HTTP status/content type, SSE event types, and failure category. It never logs the AppKey, prompt, aggregate facts, or complete request bodies. Set `ADP_DIAGNOSTICS=disable` to turn these messages off. If `.env` or `ADP_APP_KEY` is missing, the backend still starts and returns a structured `MISSING_CREDENTIALS` response so the UI can show its safe fallback.

Run `npm test` for the deterministic and mocked-ADP tests. To check the production frontend build, run `npm run build`.

## Scope

Every patient and health detail shown in the interface is fictional and labelled as synthetic demonstration data. The AI receives only whitelisted aggregate results from the deterministic analysis; it does not calculate statistics or receive raw diary records. Its output is optional, validated, and falls back to the deterministic summary on failure. It must not be used for diagnosis or medication advice.
