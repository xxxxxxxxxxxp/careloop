# CareLoop

A frontend-only menstrual migraine self-care companion prototype for a Tencent Cloud hackathon.

## Run locally

1. Install Node.js LTS (v20+).
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

To check the production build, run `npm run build`.

## Scope

This first version contains application structure, responsive navigation, and dashboard/page placeholders only. It has no medical logic, AI integration, authentication, or backend. Every patient and health detail shown in the interface is fictional and labelled as synthetic demonstration data.
